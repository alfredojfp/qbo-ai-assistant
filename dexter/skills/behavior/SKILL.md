# Aprendizaje de Usuario
**Versión:** 1.0.0 | **Dominio:** Dexter v5.0

Aprende de interacciones y sugiere acciones basadas en historial. Herramientas: aprenderinteraccion, obtenersugerencias, registrarcorreccion, obtenercontexto.

## Cuándo Usar
Consultá el system prompt o preguntale a Dexter. Esta skill se activa automáticamente cuando el LLM detecta keywords relevantes.

## Herramientas
Las herramientas específicas están definidas en `__init__.py` y se auto-descubren vía `dexter.skills`.
