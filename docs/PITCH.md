# 🧠 Dexter — QuickBooks AI Agent

## Automatización Contable con Inteligencia Artificial

**Dexter** es un agente de IA que opera QuickBooks Online mediante lenguaje natural.
El contador habla, Dexter ejecuta.

[🎥 Ver video demo](https://youtube.com) *(reemplazar con link real)*

## Funcionalidades

- 🔍 Búsqueda de clientes, vendors, cuentas, items
- ✏️ Creación de invoices, estimates, bills, pagos, depósitos
- 📊 Reportes financieros (P&L, Balance, Cash Flow, 13+ más)
- 🏦 Clasificación de bank feed con aprendizaje automático
- 📄 OCR de facturas PDF (extrae vendor, monto, fecha, IVA)
- 🔄 Multi-empresa con datos aislados
- 🛡️ Modo simulación (dry-run) para probar sin riesgo
- 🌐 Bilingüe español/inglés
